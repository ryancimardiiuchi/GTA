🎮 **Dev GTA — Seletor de Personagens com IA**

Projeto web inspirado na estética de GTA, desenvolvido com HTML, CSS e JavaScript. Permite selecionar personagens, visualizar efeitos interativos e transformar uma foto pessoal em um personagem de videogame utilizando a IA do Puter.

🚀 **Tecnologias:** HTML5, CSS3, JavaScript e Puter.js.

🎨 **Destaques:** interface temática, efeitos visuais ao passar o mouse, layout responsivo e geração de personagens personalizados com inteligência artificial.
