Projeto de seleção de personagens inspirado no universo GTA, desenvolvido para praticar desenvolvimento web, interatividade e integração com inteligência artificial. O usuário pode escolher personagens ou transformar sua própria foto em um personagem de videogame usando IA.

## 🚀 Tecnologias utilizadas

<div align="center">
  <img src="https://skillicons.dev/icons?i=html,css,js" alt="HTML, CSS e JavaScript" />
  <img src="https://img.shields.io/badge/Puter.js-IA-6C47FF?style=for-the-badge" alt="Puter.js" />
</div>

## ✨ Funcionalidades

- 🎭 Seleção de personagens.
- 📸 Envio de foto personalizada.
- 🤖 Geração de personagem com inteligência artificial.
- 🎨 Interface inspirada em jogos.
- 📱 Layout adaptável para diferentes telas.

## 🛠️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `index.html` com a extensão Live Server.

## 👨‍💻 Desenvolvido com

HTML5, CSS3, JavaScript e Puter.js.
